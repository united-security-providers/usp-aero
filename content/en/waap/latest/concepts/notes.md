# Keeping the configuration documented

As configuration can grow over time and for example some rules where put in place for a special case,
most configuration views and sections contain a "Comment" field.

This free-form text field can be used to document why the configuration needs to be like this and
should help to still understand it at a later point in time or by another administrator, or for
auditing purposes.
