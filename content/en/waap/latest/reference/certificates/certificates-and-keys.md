# Certificates & Keys

Allows to configure the certificates and CA chains required for virtual hosts or to protect TLS
connections.

## Tab "Certificates"

### Certificates & Keys

Configure certificates for virtual hosts and TLS connections here. Click the "+" icon to either
upload a certificate file or key, or to generate new ones: "Upload Key/Certificate",
"Create Self-signed Certificate" or "Create Key / CSR".

### Name

For all three options, a name must be configured. This name is a label used to reference the
certificate in other configuration screens.
