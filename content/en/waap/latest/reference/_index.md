# Reference

What every screen and every setting of Aero WAAP does, which values it accepts and what it defaults
to. The help icon next to a setting in the GUI opens its section here directly.

Use this section while looking at a screen. To see how the pieces fit together, start with
[How a request is processed](../concepts/request-flow); to work through a complete task, see
[Getting started](../getting-started), [Application integration](../application-integration/) or
[Application protection](../protection/).

* [GUI](gui/) - one page per screen of the management GUI, in the order of its navigation
* [TLS versions, ciphers and algorithms](tls-settings) - the shared TLS settings block
* [Value types](value-types) - the value formats that recur across settings
* [Glossary](glossary)
