# Reference

One page per screen of the Aero WAAP management GUI, following the order of its navigation. Every
setting has its own section stating what it does, which values it accepts and what it defaults to.

The help icon next to a setting in the GUI opens that setting's section here directly.

Use this section while looking at a screen. To see how the pieces fit together, start with
[How a request is processed](../concepts/request-flow); to work through a complete task, see the
[How-to guides](../how-to/).

* [Listeners](listeners/) - the addresses and ports WAAP accepts connections on
* [Virtual Hosts](vhosts/) - the hostnames it serves, their routes and their protection settings
* [Backends](backends/) - the application servers it forwards requests to
* [Certificates](certificates/) - server certificates, CA certificates and ACME providers
* [Local Files](local-files/) - static content and error pages served by WAAP itself
* [TLS versions, ciphers and algorithms](tls-settings) - the shared TLS settings block
* [Glossary](glossary)
