# Install a component

To extend the functionality of the appliance additional components can be installed:

1. Open [Components](../../reference/gui/components.md) and click "Add Component"
2. In the visible pop-up, select the new component you want to install, and click "Add" 
3. The installation will be initiated, this will take some time. As soon as the installation is completed, 
   the new component is listed in the overview, and the new navigation icon appears in the module switcher.
