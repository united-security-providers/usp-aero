# Reference

One page per screen of the Aero Platform management GUI, following the order of its navigation. Every
setting has its own section stating what it does, which values it accepts and what it defaults to.

The help icon next to a setting in the GUI opens that setting's section here directly.

Use this section while looking at a screen. For how a change becomes active, read
[Configuration lifecycle](../concepts/configuration-lifecycle) first; to work through a complete
task, see the [How-to guides](../operations/).

* [Configuration](GUI/configuration/) - system, network, high availability, container, certificates and log settings
* [Configuration Deployment](GUI/deployment/) - revisions, deployment and rollback
* [System Management](GUI/system-management/) - operating system updates and high availability status
* [Components](gui/components.md) - the installed feature components and their versions
* [User Management](GUI/user-management/) - local users, roles and the user profile
* [Backup](GUI/backup/) - backup jobs, targets and restore
* [Live Log](../operations/live-log.md)
* [Configuration validation errors](validation-errors) - every validation message and what to do about it
* [Roles and permissions](../concepts/roles-and-permissions.md)
* [Glossary](glossary)
