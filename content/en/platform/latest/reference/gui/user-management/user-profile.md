# User profile and password

Opened from the user profile menu in the top navigation bar (see
[Management GUI overview](../../concepts/gui-overview)).

## User Profile

### Username

Your account name, used to log in. It cannot be changed here.

### Display name

Your name as shown in the GUI.

### E-Mail

Your e-mail address.

## Change Password

### New password

The new password for your own account.

### Repeat new password

Must match the new password exactly.
