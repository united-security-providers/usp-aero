# User profile and password

Opened from the user profile menu in the top navigation bar. (see
[Management GUI overview](../../../concepts/gui-overview)). Here the user can change his own password.

## User Profile

### Username {#username}

Your account name, used to log in. It cannot be changed here.

### Display name {#displayname}

Your name as shown in the GUI.

- **Values:** free text, at most 32 characters
- **Required:** yes

### E-Mail {#email}

Your e-mail address.

- **Values:** a valid e-mail address, at most 254 characters
- **Required:** yes

### Change Password {#editProfileChangePasswordButton}

Opens the Change Password dialog for your account.

## Change Password

### New password {#newPassword}

The new password for your own account.

- **Values:** free text, at least 8 characters
- **Required:** yes

### Repeat new password {#repeatPassword}

Must match the new password exactly.

- **Values:** must match the value entered in New password
- **Required:** yes
