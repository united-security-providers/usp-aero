# Local Users

Configure local system user accounts here. Click the "Add User" button to add a new user. Click the
"trashcan" icon to delete a user.

## Create User

When adding a new user, the following fields must be filled in:

### Username

The user account name used for the login.

### Display name

The display name for the user (e.g. the real name and surname).

### E-Mail

The e-mail address of the user.

### Role

Select the role that the user should have. See
[Roles and permissions](../roles-and-permissions) for what each role can do.

### Password

The password used by this user account for the login.
