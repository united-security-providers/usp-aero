# Components

This screen lists the software components installed on this appliance, their current version, and
whether an update is available.

### Aero Management

The Aero Management UI itself.

### WAAP

The Envoy-based Web Application Firewall "Aero WAAP".

## Add Component

Deploys a new component onto this appliance.

## Update component

Updates a component to the latest available version.

## Rollback component update

Reverts a component to the version it had before its last update.

## Reload inventory

Reloads the list of installed components and their versions from the component deployment inventory.
