# Management GUI

One page per screen of the management GUI, following the order of its navigation. Every setting has
its own section; the help icon next to a setting in the GUI opens it directly.

* [Configuration](configuration/) - system, network, high availability, container, certificates and log settings
* [Configuration Deployment](deployment/) - revisions, deployment and rollback
* [System Management](system-management/) - operating system updates and high availability status
* [Components](components) - the installed feature components and their versions
* [User Management](user-management/) - local users and the user profile
* [Backup](backup/) - backup jobs, targets and restore
