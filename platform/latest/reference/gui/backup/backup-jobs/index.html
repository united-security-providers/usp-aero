Backup jobs

In the "Automated Backups" section, backups can be configured to be performed automatically at certain times and dates. Click the "+" icon to add a new backup job.

Automated Backups

Lists every configured backup job.

Name

The name (label) for this backup job.

Target

Where this job stores its backup data: Local, or the name of a configured backup target .

Schedule

The job's schedule, shown as configured.

Type

Whether the backup data produced by this job includes the private key files.

  • Values: Full (incl. Keys), Full (no Keys)

Edit

Opens this job for editing.

Delete

Deletes this backup job.

Trigger Backup job now

Runs this backup job immediately, without waiting for its schedule.

Check connection

Verifies that the job's target host can be reached and authenticated against with the target's configured settings. Only available for jobs with a remote target.

Add Backup Job

When adding a new backup job, specify the following:

Name

The name (label) for this backup job.

  • Values: free text
  • Required: yes

Target

Specifies where to store the backup data — see Backup targets for how a target is configured. Click the "+" icon to add a new target, the pencil icon to edit the selected one, or the key icon to show its SSH public key (see Backup Host Public Key ); the key icon only appears once a remote target is selected.

  • Values: Local, or the name of a configured backup target
  • Default: Local

Schedule (cron)

Defines the scheduling for this backup job in common cron syntax.

  • Values: cron expression
  • Required: yes

Type

Defines if the backup data should contain all the private key files or not.

  • Values: Full (incl. Keys), Full (no Keys)
  • Default: Full (incl. Keys)
  • Required: yes
