# Requirements

## System requirements

The recommended minimum hardware requirements for running the USP Aero platform are as follows:

* 8 GB RAM
* 40 GB disk space
* 4 CPU cores

The Aero platform supports both actual x64 hardware as well as virtual machines (VMWare, VirtualBox, Hyper-V).
