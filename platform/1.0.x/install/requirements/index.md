# System Requirements

The recommended minimum hardware requirements for running the USP Aero platform are:

* CPU: 4 cores
* Memory: 8 GB
* Disk space: 40 GB

The Aero platform supports current `x64` hardware as well as virtual machines (VMWare, VirtualBox, Hyper-V).
