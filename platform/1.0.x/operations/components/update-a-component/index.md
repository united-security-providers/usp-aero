# Update a component

1. Open [Components](../../reference/gui/components.md) and check the Status column for an available update.
2. Click "Update component" on the component to update.
3. Confirm the update from the current to the new version.

If an update causes problems, use "Rollback component update" on the same component to revert it to
the version it had before the update.
